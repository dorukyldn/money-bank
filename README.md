# Türkiye İş Verisi

Türk kamu ve iş verisi için Apify Actor'leri, MCP sunucusu ve (talep kanıtlanırsa) abonelik SaaS.

- `durum.md` — güncel durum ve onay bekleyenler
- `kararlar.md` · `metrikler.md`
- `docs/hukuk/kaynaklar.md` — her kaynağın robots / kullanım koşulu / erişim kontrolü
- `docs/asama0/` — rakip tablosu ve aday puanlaması
- `scripts/apify_rakip_ara.py` — Apify Store rakip tarayıcı (`python3 scripts/apify_rakip_ara.py "ekap" +ekap`)
- `actors/`, `saas/`, `pazarlama/`
